# Digital Shield — Аудит цифровой безопасности

Локальное клиентское веб-приложение для анализа устойчивости паролей, открытости профиля и цифрового следа (OSINT-моделирование).

🌐 **GitHub Pages:** https://artboi5436-svg.github.io/site/

## Возможности
- **Проверка пароля:** оценка энтропии, длины, разнообразия символов и выявление персональных данных в пароле.
- **Оценка профиля:** моделирование открытости сведений (никнейм, возраст, локация, контакты).
- **Цифровой след:** выявление поведенческих рисков и геометок.
- **Сводный индекс безопасности:** расчет интегрального риска от 0 до 100 с детализацией по категориям.
- **Моделирование сценариев угроз:** причинно-следственные цепочки («Открытые сведения → Связка данных → Возможный риск → Способ защиты»).
- **Экспорт отчётов:** выгрузка подробных HTML и TXT отчётов.
- **100% приватность:** все расчёты выполняются локально в браузере пользователя, данные никуда не отправляются и не сохраняются.
